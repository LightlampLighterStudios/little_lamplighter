# Little Lamplighter

## Before working on the project

This project uses **Git LFS** for large files such as images, audio, fonts, models, and Unity packages.

First, make sure Git is installed, then install Git LFS from:

https://git-lfs.com/

Then run:

```bash
git lfs install
```

Then clone the repo and pull the large files:

```bash
git clone https://github.com/lucasfgp/little_lamplighter.git
cd little_lamplighter
git lfs pull
```
